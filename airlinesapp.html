Airlines Mobile Application

JavaScriptHTMLCSSSQL DatabasesAPIs
Project Overview ⌄

This project allows each airline to see different reports, track airline operations, and easily access data. Airline staff can generate reports over a chosen time period, export them to PDF or CSV, and check live belt status for their flights from a mobile friendly interface.

Project Goal ⌄

The goal is to give each airline its own mobile view into its operations at the airport, so staff can pull the reports and belt status they need on the spot instead of requesting the information from another department.

Tools Used ⌄

Tools used were JavaScript, HTML, and CSS on the front end, with SQL Databases and APIs supplying the report and belt status data behind it.
